Sincronização entre noivo e noiva

Opcional: configura Firebase para os dois utilizarem a mesma base de dados em telemóveis diferentes.

A sincronização na nuvem exige um projecto Firebase, Firestore e contas de autenticação. Sem esta configuração, a aplicação funciona localmente neste navegador.

Dados e segurança

Os dados locais ficam neste navegador. Exporta cópias de segurança regularmente. Para partilhar, ambos devem usar o mesmo projecto Firebase, código de casamento e contas autorizadas nas regras do Firestore.
